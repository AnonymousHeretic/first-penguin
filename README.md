# 🐧 퍼스트 펭귄 (First Penguin)

무너지는 빙하 위에서 서로 부딪혀 상대를 바다로 밀어내는 펭귄 파티 게임.
바다엔 능력을 주는 물고기가 있지만, 먼저 뛰어든 펭귄을 노리는 고래도 있다.

- 플레이: https://first-penguin-eta.vercel.app
- 모드: 대전(사람 최대 2 + CPU, 최대 4마리) / 스테이지(솔로 5단계)
- 조작: P1 `WASD` 이동 · `Q`/`Shift` 대쉬 · `E`/`Space` 점프 — P2 `IJKL`/방향키 · `U` 대쉬 · `O` 점프
- 모바일: 가로 화면, 왼쪽 드래그 이동 + 오른쪽 대쉬/점프 버튼

빌드 과정 없는 단일 `index.html` (HTML + CSS + JS). `main`에 push하면 Vercel이 자동 배포한다.
